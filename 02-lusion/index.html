SIG(Signal Intensity Gradient)는 혈관벽 전단응력의 대리 지표입니다. 추가 촬영·조영제·시뮬레이션 없이 MRA 신호만으로 계산해, 파랑에서 빨강까지의 컬러맵으로 혈관벽에 입힙니다.

(03)HOW NEUFLOW WORKS — 구동 프로세스
01/ 05
  1. INPUT

    TOF-MRA 불러오기

    기존에 촬영한 MRA 영상을 그대로 사용합니다. 추가 촬영도, 조영제도 필요 없습니다.

  2. RECONSTRUCT

    3D 혈관 재구성

    자동 분할로 3차원 혈관 구조를 생성합니다. 흑백 슬라이스가 하나의 입체로 일어섭니다.

  3. SIG MAPPING

    SIG 컬러 매핑

    혈류역학 데이터를 색으로 시각화합니다. 파랑에서 빨강까지, 혈관벽에 SIG가 입혀집니다.

  4. MEASURE

    ROI 정밀 측정

    관심 혈관의 지름·길이·SIG 수치를 측정해 판독에 정량 근거를 더합니다.

  5. REPORT

    뇌혈관 건강 보고서

    환자 설명용 리포트를 자동으로 생성합니다. 환자가 직접 보고 이해하는 한 장.

(04)FEATURED CAPABILITIES — 주요 기능

판독실에서 진료실까지.

판독에 정량 근거를 더하고, 환자에게 직관적으로 설명하며, 정기 추적 관리로 이어집니다. NeuFlow의 여섯 가지 기능.

01+
3D • SIG • QUANT

3D 컬러 & SIG 정량 데이터

전체 혈관과 선택 혈관의 혈류역학 특성을 수치로 확인합니다.

02+
DIAMETER • LENGTH • SIG

혈관별 정밀 측정

관심 혈관의 지름, 길이, SIG를 구간별로 측정합니다.

03+
PACS • DICOM • WORKFLOW

PACS 연동

기존 병원 시스템에 그대로 연결합니다. 판독 흐름은 바뀌지 않습니다.

04+
3D • 2D • OVERLAY

3D·2D 중첩

2D 슬라이스 위에 3D 컬러 혈관을 겹쳐 정확한 위치를 확인합니다.

05+
REPORT • PATIENT • EXPLAIN

뇌혈관 건강 보고서

환자가 이해하는 한 장의 리포트를 자동으로 만듭니다.

06+
GUIDE • PERSONAL • CARE

맞춤 건강 가이드

개인별 뇌혈관 관리 가이드로 정기 추적 관리까지 이어집니다.
