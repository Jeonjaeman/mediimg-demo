OVERVIEW · 무엇을 측정하나요

무엇을 측정하나요?

뇌혈관 TOF-MRA의 DICOM 원본 영상을 분석합니다. 의료진이 선택한 혈관 영역의 SIG 기반 혈류량 값과 상한·하한, 영역 간 비율, 혈관 반지름·길이·각도 정보를 제공합니다. 결과는 3차원 혈관 영상 위에 색상으로 표시됩니다.

  • INPUT뇌혈관 TOF-MRA DICOM 원본 영상
  • OUTPUTSIG 기반 혈류량 값 · 상한·하한 · 영역 간 비율 · 혈관 반지름·길이·각도
  • VIEW3차원 혈관 영상 위 색상 표시
이미지 예정 · FloCal 대표 화면
PC-MR / FLOCAL · 기존 방법과의 차이

기존 방법과의 차이

PC-MR은 속도 부호화 영상을 통해 혈류량을 계산하는 반면, FloCal은 기존 TOF-MRA 영상의 SIG를 활용해 혈류량 값을 산출합니다. 혈관의 형태와 혈류량 관련 정량정보를 3D 컬러 영상으로 함께 살펴볼 수 있습니다.

이미지 예정 · 영상 불러오기 화면
F.01

TOF-MRA 영상 활용

로컬 또는 PACS에 저장된 뇌혈관 TOF-MRA DICOM 영상을 불러와 분석합니다.

이미지 예정 · 3차원 혈관 화면
F.02

3차원 혈관 확인

뇌혈관을 3차원으로 구현하고, 2차원 단면 영상과 함께 확인합니다. 회전과 확대·축소를 지원합니다.

이미지 예정 · 혈류량 산출 화면
F.03

SIG 기반 혈류량 산출

의료진이 선택한 관심 영역의 혈류량 값과 상한·하한을 산출합니다. 신호강도구배(SIG)를 바탕으로 계산합니다.

이미지 예정 · 색상 표시 화면
F.04

수치를 색상으로 표시

산출값을 3차원 혈관의 관심 영역에 색상으로 표시합니다. 색상 범위는 사용자가 설정하며, 색 자체가 정상·질환 판정은 아닙니다.

이미지 예정 · 영역 간 비교 화면
F.05

혈관 영역 간 비교

선택한 영역의 혈류량 비율과 반지름 비율을 확인합니다. 혈관 반지름·길이·각도 정보도 함께 제공합니다.

이미지 예정 · 보고서 화면
F.06

결과를 보고서로 정리

분석 결과를 PDF 보고서로 생성하고, 로컬에 저장하거나 PACS로 전송할 수 있습니다.

HOW IT WORKS · 사용 과정

영상 불러오기에서보고서까지, 5단계.

  1. STEP 01
    이미지 예정 · 영상 불러오기

    영상 불러오기

    로컬 또는 PACS의 TOF-MRA DICOM 영상을 불러옵니다.

  2. STEP 02
    이미지 예정 · 혈관 영상 확인

    혈관 영상 확인

    3차원 혈관과 단면 영상을 확인하고 분석할 부위를 살펴봅니다.

  3. STEP 03
    이미지 예정 · 관심 영역 선택

    관심 영역(ROI) 선택

    의료진이 분석할 혈관 영역을 선택하고 혈관명을 지정합니다.

  4. STEP 04
    이미지 예정 · 산출 결과

    산출 결과 확인

    선택 영역의 SIG 기반 혈류량 값과 색상 표시를 확인합니다.

  5. STEP 05
    이미지 예정 · 보고서 생성

    보고서 생성

    분석 결과를 PDF 보고서로 정리해 저장하거나 PACS로 전송합니다.

FOR USERS사용자별 혜택

  1. 01

    뇌혈관 분석 정보의 확장

    기존 TOF-MRA 영상에서 뇌혈관의 구조뿐 아니라 SIG 기반 혈류량 정보를 추가로 확보하여, 혈류역학적 특성을 다각도로 살펴볼 수 있습니다.

  2. 02

    정량정보 기반의 진료 지원

    혈관별 혈류량 산출값과 영역 간 비율을 수치 및 3D 컬러 영상으로 확인하고, 이를 환자 상태 검토와 진료 상담에 활용할 수 있습니다.

  1. 01

    뇌혈관의 흐름 이해

    기존 MRA에서 확인하는 혈관의 형태를 넘어, SIG 기반 혈류량 정보를 의료진의 설명과 함께 살펴보며 자신의 뇌혈관 상태를 이해할 수 있습니다.

  2. 02

    더 구체적인 뇌혈관 건강 상담

    뇌혈관 구조와 혈류량 관련 정량정보를 바탕으로 의료진과 검사 결과를 구체적으로 상담하고, 개인의 건강 상태에 대한 이해를 높일 수 있습니다.

FAQ

자주 묻는 질문

Q1어떤 MRI 영상이 필요한가요?

뇌혈관 TOF-MRA의 DICOM 원본 영상이 필요합니다. 일반 뇌 MRI나 캡처 이미지만으로 같은 분석을 하는 제품은 아닙니다.

Q2색상만으로 질환을 판단하나요?

색상은 설정 범위 내 SIG 기반 혈류량 값을 나타냅니다. 정상·위험을 자동 판정하는 색이 아니며, 결과는 전문 의료진이 해석합니다.

Q3환자가 직접 사용하는 제품인가요?

인가받은 전문 의료인이 사용하는 영상 분석 소프트웨어입니다. 추가 검사나 진료 계획은 의료진이 영상과 환자 상태를 함께 고려해 결정합니다.
